# Viksit Gujarat Implementation Roadmap Progress Monitor

Monthly progress tracker for the Viksit Gujarat 2047 roadmap action steps of the Sports, Youth & Cultural Activities Department (SYCAD), Government of Gujarat.

Live: https://a-gyani.github.io/vg-tracker/

Plain HTML, CSS and JavaScript; no build step. Open `index.html` to run it locally.
Currently in test mode: data is kept in each person's own browser. Shared data and real logins (Firebase) come later.
